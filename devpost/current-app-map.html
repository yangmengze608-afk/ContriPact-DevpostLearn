Current deterministic app map

Input → validate → exact cents → snapshot → compare → export

  1. src/main.tsx opens src/allocation/AllocationApp.tsx. Every input edit sets the dirty flag and disables export.
  2. src/allocation/allocation.ts → calculate validates bounded strings, computes BigInt quotas, floors cents and awards remainder cents in deterministic order.
  3. The React page stores current and previous snapshots. A failed calculation never overwrites a successful snapshot.
  4. createExport checks freshness and recomputes the result before a real JSON Blob download.
  5. tests/allocation.test.ts covers examples, invalid boundaries, export and 5,000 seeded invariant cases.

Engineering takeaway: trace a visible amount back through the snapshot, quota and validated input; verify the downloaded artifact, not just the screen. No new learner reflection or hands-on review is claimed.

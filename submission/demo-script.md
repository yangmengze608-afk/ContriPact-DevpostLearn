# English demo script

AI-assisted narration for an actual browser operation recording. Synthetic system voice; no music.

## 00 seconds
Small competition teams need to understand how a captain turns contribution scores into prize amounts. ContriPact makes that calculation inspectable. This single-device proof of concept starts with three fictional members and a one hundred yuan prize.

## 18 seconds
All three scores are one. Calculate shows the exact shares and amounts. Alex receives thirty-three yuan and thirty-four cents. Blair and Casey each receive thirty-three yuan and thirty-three cents. The entire prize is allocated.

## 34 seconds
The audit shows the formula and the rounding. Each exact quota is rounded down in integer cents. Remaining cents go to the largest remainders. Equal remainders follow the member list order, so Alex receives the extra cent.

## 49 seconds
Now change Blair’s score from one to two. The previous result is visibly marked as needing an update. Export is disabled until the calculation is refreshed.

## 60 seconds
Recalculate gives Blair half the prize, with a quarter each for Alex and Casey. The table preserves the previous amounts and shows exactly how much each payout changed.

## 74 seconds
Export downloads a real JSON record. It contains the input names and scores, the prize, the rounding rule, and both calculation snapshots, so the arithmetic can be reproduced.

## 86 seconds
The planning documents are available inside the page and at the repository root. Scope defines the captain, the problem, the core loop, and what this proof of concept deliberately excludes.

## 100 seconds
The product requirements define validation, stale-result behavior, comparison and acceptance conditions. The technical specification explains the data, exact-cent algorithm, export format and tests.

## 113 seconds
Codex used the installed official six-step Devpost Learn pack, with the user’s supplied product answers. No new interview or learner reflection is claimed. Automated tests and actual browser checks verify the working loop.

## 128 seconds
Transparent arithmetic does not prove objective scores or guarantee fairness. This tool helps a team inspect a rule; people still decide the scores.
